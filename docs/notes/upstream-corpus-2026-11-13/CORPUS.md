## Секция 2. Путь контрибуции 2026

1. **Четыре официальных канала**: GitHub PR / Phabricator (reviews.freebsd.org) / Bugzilla attachment / прямой git. GitHub PR предпочтителен для простых изменений; не открывать PR и Differential на одно изменение одновременно. Receipt: `/usr/src/CONTRIBUTING.md`.
2. **Критерии GitHub PR**: substantive; готов к лендингу ≤10 мин коммиттером; CI зелёный; ответ на фидбек ≤1 месяц (иначе close); <~10 файлов / <~200 строк; каждый логический чендж = отдельный коммит; author = имя + валидный email (noreply.github.com нельзя); `Signed-off-by:` (DCO) сильно желателен; fixup-коммиты сквошить; правки = rebase + force-push; `tools/build/checkstyle9.pl` без ошибок; если чинит баг — `PR: <bugnumber>` в сообщении. Receipt: `/usr/src/CONTRIBUTING.md`.
3. **Формально «not an official way to submit patches at this time»**, но landing-процедура документирована (§5.8): коммиттер cherry-pick'ает PR-ветку, добавляет `Pull Request: https://github.com/freebsd-src/pull/$PR` + `Reviewed by:`, пушит, закрывает PR. Receipt: `/tmp/fbsd-ai/guide.md:1951-2016` (снапшот Committer's Guide от 2026-09-26).
4. **Phabricator жив**: reviews.freebsd.org обслуживал наши фетчи 2026-11-12 (d50650.md, d54817.md); в октябре 2026 кратко снимался из-за PHP-уязвимости и поднят. Рабочий инструмент — `git arc` (devel/freebsd-git-arc). Receipts: guide.md §16:2659-2675; Q3 report intro.
5. **Pre-commit review нормы (§8)**: все нетривиальные изменения — через ревью; обязателен явный «looks good»; таймауты не заменяют ревью; пинг: срочный — раз в 2 дня, вежливый — раз в неделю; большие патчи сплитить; ревьюить чужое («goodwill is our currency»); аппрув — только subject-matter expert. Receipt: guide.md:2255-2277.
6. **Bugzilla-путь обновился**: linimon установил «convert to Attachment using git diff — **new preferred submission method for Bugzilla**» (PR 300130 c2, 2026-10-28). Очереди мейнтейнеров реальны: rmacklem — «I'll have time to look at this around the end of Nov» (c17, 2026-11-10). Receipt: `/tmp/fbsd-ai/c300130.txt`.
7. **Not-committers (§23)**: тот же гайд применим; ментор вносит в contrib-additional.adoc. Receipt: guide.md:3379-3386. Документ свежий: «Last modified on: September 26, 2026 by Vladlen Popolitov» (guide.md, хвост).
