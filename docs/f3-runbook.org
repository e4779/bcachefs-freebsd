* Исследование (зафиксировано 2026-11-06, источники — исходники releng/15.1 + клон tools + gh)
Полную выжимку с file:line см. docs/notes/19a-dogfood-engine.md «РАЗГОВОР С ИСТОЧНИКАМИ». Ключевое:
- fuser read-loop надёжен (EAGAIN/EINTR ретраи; partial read убивает сессию, не теряет сообщение); молчаливая потеря возможна только в reply-пути (writev err → kernel ждёт unique вечно).
- Kernel-side lost-wakeup исключён (push+wakeup под одним ms_mtx).
- Утечки svcj-jail при out-of-band kill: чистится только service X onestop (внутри него jail -r); console-логи сервисов в /var/log/svcj_<name>_console.log.
- Инциденты #1/#2: артефакты tmp/fuse-stall-incident{1,2}/.
