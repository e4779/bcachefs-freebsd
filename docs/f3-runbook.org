** DONE P0: root-cause найден и УТОЧНЁН утром 2026-11-07 — семантика спина, не атомики :wedge:
Финальная цепочка (lldb core + чтение исходников утром): FUSE read -> btree ops -> six_unlock -> six_lock_wakeup -> guard(raw_spinlock)(&lock->wait_lock), а raw_spinlock в порте = НЕ-РЕКУРСИВНЫЙ pthread_mutex = СПИТ. Держатель wait_lock спит -> fuser-0 блокируется навсегда на мьютексе (вчерашняя теория 'atomic64-бакеты' ошибочна: ATOMIC64_SPINLOCK нигде не определён, атомики нативные lock-free; PC-атрибуция по оптимизированному inline размывала кадр). ФИКС: spinlock_types.h -> pthread_spin (семантика ядра: под spinlock не спят; циркулярные sleep-ожидания исчезают классом). Оверлей: overlay/files/include/linux/spinlock_types.h.
Уроки: catcher-v2 truss УБИВАЛ демона SIGTRAP при detach (signal 5, core dumped — случайно дало лучший артефакт); v3 без truss; core-дамп через kill -5 = легитимный инструмент (с остановкой heal).
