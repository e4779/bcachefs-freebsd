** DONE P0: root-cause найден и УТОЧНЁН утром 2026-11-07 — семантика спина, не атомики :wedge:
Финальная цепочка (lldb core + чтение исходников утром): FUSE read -> btree ops -> six_unlock -> six_lock_wakeup -> guard(raw_spinlock)(&lock->wait_lock), а raw_spinlock в порте = НЕ-РЕКУРСИВНЫЙ pthread_mutex = СПИТ.
